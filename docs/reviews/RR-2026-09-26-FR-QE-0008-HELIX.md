Primary source: Berthusen et al., *Experimental validation of a compact fault-tolerant architecture for trapped ions*, arXiv:2609.03194v1, https://arxiv.org/abs/2609.03194v1.

## Decision

**ADMIT as IN-007** to FR-QE-0008. The Helios [[20,2,6]] C4-Helix architecture is a distinct evidential object from IN-004's earlier Microsoft/Quantinuum logical-circuit demonstrations and IN-006's Google drift-control experiment. The authors report repeated QEC at 4.6 (+6.2/−2.6) × 10⁻⁵ error per logical qubit per cycle, a two-logical-qubit Clifford benchmark at 2.8 (+1.0/−1.6) × 10⁻⁴ error per Clifford, and a chain-map interface to a distance-5 surface code with a heterogeneous three-logical-qubit GHZ fidelity lower bound of 99.925 (+0.068/−0.245)%. Corresponding encoded implementations beat unencoded physical baselines without postselection. The work is an interested-party primary preprint on Quantinuum hardware, without established independent replication.

This is integrated architectural and logical-operation evidence. A distance-5 interface and a distance-6 code are not an experimental curve of logical-error suppression with increasing code distance. The paper's future-fidelity simulation is not measured performance. No useful fault-tolerant workload, application-scale overhead or sustainable commercial economics follows.
