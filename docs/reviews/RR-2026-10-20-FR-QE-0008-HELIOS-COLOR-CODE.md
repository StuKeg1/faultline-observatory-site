# Normal Record Review — FR-QE-0008

Date: 2026-10-20  
Candidate: Lavasani et al., *Quantum error correction well below the color code threshold*, arXiv:2610.24077v1. Submitted 16 October 2026.  
Origin: new-evidence candidate held outside LPR-001-D56.

## Decision

**ADMIT as IN-009. Reaffirm RESOLVING / VS-04 in AS-005.**

The primary preprint reports experimental below-threshold triangular colour-code operation on Quantinuum Helios at distances 3, 5 and 7. Logical memory reaches 5 (+4/−2) × 10^-6 error per syndrome-extraction round at distance 7, with Λ = 12 (+3/−2) per successive distance increase. Two-qubit Clifford randomized benchmarking also shows below-threshold scaling from distance 3 to 5, reaching 7 (+3/−3) × 10^-5 error per logical two-qubit Clifford with Λ = 9 (+8/−3).

This is materially relevant to the record because IN-007 did not measure a suppression curve across increasing code distances. IN-009 supplies direct increasing-distance evidence on trapped-ion hardware and broadens the record beyond Google's superconducting surface-code scaling.

## Boundaries

- The evidence is first-party Quantinuum research, not independent replication of the trapped-ion result.
- Experimental distance scaling reaches d=7; larger-code/application-scale projections are not measurements.
- The work does not demonstrate below-threshold magic-state preparation.
- It does not establish sustained universal fault-tolerant computation or application-scale resource economics.
- Quantinuum's Apollo/resource projections are not admitted as empirical scale-up evidence.

Therefore the evidence strengthens convergence but does not satisfy the full outcome-based AT-001. Pressure State remains RESOLVING and Verification Stage remains VS-04.
