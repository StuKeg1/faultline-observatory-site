# Claim Class — parked analytical hypothesis (2026-11-20)

**Status: PARKED HYPOTHESIS — not an approved taxonomy, programme commitment, or change to FCIF.** A future cross-programme classification might describe **what the canonical claim primarily asserts**, distinct from **Programme** (where the contested frontier belongs), **Pressure State** (how evidence bears on the claim), and **Verification Stage** (how far verification has progressed). Candidate assertion types for exploration—not definitions—are **existence**, **performance**, **mechanism**, **scalability**, and **deployment/operation**; reproducibility is deliberately excluded because it is generally a test of evidence, not the proposition asserted, and scalability and deployment must not be conflated. Revisit only when a concrete cross-programme research question requires this distinction. A first, non-canonical pilot would classify the **primary assertion** of 10 varied existing records across all four programmes using only their canonical claim statements and shared provisional definitions, recording secondary assertions as notes. Two models (e.g. Claude and ChatGPT) should classify the same cases independently; disagreement is an ambiguity signal, not evidence that agreement establishes validity. Review ambiguous or multi-class cases and whether classifications duplicate FCIF before considering further adoption; corpus size alone is not an adoption gate. **No classification values should be populated, made public, or used for analytics under this proposal.** Separately, remove the one-off visible `Claim Class` row for FR-QE-0001 in a small follow-up UI PR while preserving the stored canonical value; PR #272 remains strictly citation-scoped.
