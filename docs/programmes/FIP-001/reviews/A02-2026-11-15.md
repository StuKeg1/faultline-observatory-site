## Date semantics: do not conflate
1. `record.claim.openedDate`: a record opening field, separate from actual assessment issue chronology.
2. `assessment.date`: stored canonical value, preserved for historical provenance.
3. `getAssessmentHistory(record)[].date`: governed display/effective historical date when LAD-001 has a specific overlay.
4. `recordedDate`: original canonical date retained when an overlay changes the public presentation.
5. `mutationLog[].date` and `openQuestions[].raisedDate`: independent legacy metadata whose historical precision is not automatically fixed by qualifying AS-001.
6. Modern subsequent assessments with verified dates are not part of the legacy AS-001 pilot.
