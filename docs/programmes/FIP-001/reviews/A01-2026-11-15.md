### Root cause of false positive
The initial assessment counter used the pattern `\\bid:\\s*["'](AS-\\d+)`, which matches JavaScript object keys like `id: "AS-003"` but **not** quoted JSON-style keys such as `"id": "AS-003"`. Each of the four disputed assessment objects uses the quoted-key form in the very same canonical source modules. The auditor incorrectly interpreted a parsing failure as missing content. Existing issuance mutations and review receipts were corroborating actual present assessments, not proof of absent entries.
